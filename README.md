💻 IT Support — Система керування IT-заявками
IT Support — вебзастосунок для автоматизації процесу обробки заявок на ремонт та технічне обслуговування комп'ютерної техніки. Система дозволяє користувачам створювати заявки, відстежувати їхній статус, а адміністраторам і менеджерам — керувати процесом виконання робіт.

📌 Основні можливості
👤 Користувач
Реєстрація та авторизація за допомогою електронної пошти й пароля.
Створення заявок на ремонт обладнання.
Перегляд власних заявок.
Відстеження статусу виконання заявки.
Перегляд історії змін статусу.
Отримання сповіщень про оновлення заявок.
Пошук заявок та фільтрація за статусом.
Редагування особистих даних і контактного телефону.
Зміна пароля.
Видалення облікового запису.

Перегляд усіх заявок на ремонт.
Контроль загальної кількості заявок.
Перегляд статистики нових, активних, завершених і прострочених заявок.
Зміна статусу заявки.
Призначення пріоритету.
Встановлення термінів виконання.
Пошук і фільтрація заявок.
Експорт звітів у форматі CSV.
🔐 Адміністратор
Перегляд усіх заявок і користувачів.
Керування обліковими записами.
Зміна ролей користувачів.
Видалення користувачів.
Зміна статусів заявок.
Редагування інформації про виконання ремонту.
Перегляд статистики роботи системи.
Фільтрація заявок за датою, статусом і пріоритетом.

🚀 Встановлення та запуск
1. Клонування репозиторію

bash
git clone https://github.com/Lemonchis/IT-Support.git
2. Перехід до директорії

bash
cd IT-Support
3. Налаштування Supabase
Для роботи системи необхідно мати проєкт у Supabase.

У файлі js/supabase.js налаштовується підключення до бази даних:


javascript
import { createClient } from
  'https://esm.sh/@supabase/supabase-js@2';

const SUPABASE_URL = 'YOUR_SUPABASE_URL';
const SUPABASE_ANON_KEY = 'YOUR_SUPABASE_PUBLISHABLE_KEY';

export const supabase = createClient(
  SUPABASE_URL,
  SUPABASE_ANON_KEY
);
Замість демонстраційних значень потрібно вказати URL власного проєкту та його публічний ключ.

Важливо: не використовуйте service_role або секретний ключ у клієнтському JavaScript.

4. Налаштування бази даних
У Supabase Dashboard відкрийте SQL Editor та виконайте SQL-скрипти в такому порядку:

supabase/sql/supabase-schema.sql
supabase/sql/supabase-work-order-fields.sql
supabase/sql/supabase-request-notifications.sql
Перед виконанням перевірте наявність основної таблиці repair_requests, оскільки SQL-скрипти розширюють її структуру.

Скрипти налаштовують:

Профілі користувачів.
Ролі та права доступу.
Політики Row Level Security.
Історію зміни статусів заявок.
Систему сповіщень.
Функції керування профілями та заявками.
5. Запуск застосунку
Оскільки проєкт використовує JavaScript ES Modules, його потрібно запускати через локальний вебсервер.

Наприклад, за допомогою VS Code встановіть розширення Live Server та відкрийте index.html через Live Server.

Або скористайтеся Python:


bash
python -m http.server 8000
Після запуску відкрийте:


text
http://localhost:8000
